# FamilyLocalTree 🌳

Веб-приложение для создания и управления генеалогическим деревом.

## Возможности

- 📊 **Визуализация дерева** — интерактивное отображение родословной
- ➕ **Добавление/редактирование** — управление участниками дерева
- 🔍 **Фильтры** — поиск по городам, датам рождения, родственным связям
- 💾 **Хранение данных** — всё хранится локально в браузере (localStorage)
- 📦 **Экспорт/импорт** — сохраняйте и делитесь деревом в JSON формате
- 🔎 **Масштабирование** — удобное перемещение по большому дереву

## Использование

Просто откройте `index.html` в любом современном браузере.

### Добавление человека
1. Нажмите "+ Добавить человека"
2. Заполните данные (имя обязательно)
3. Добавьте связи с другими людьми
4. Нажмите "Сохранить"

### Фильтрация
Используйте боковую панель для фильтрации:
- По городу
- По году рождения (диапазон)
- По типу связи (родители, дети, супруги, siblings)

### Экспорт/импорт
- Экспорт: скачивает JSON файл с деревом
- Импорт: загружает ранее сохранённое дерево

## Технологии

- Чистый JavaScript (без backend)
- HTML5 + CSS3
- LocalStorage для хранения данных
